## Finding 1 — Opus 4.7 is NOT clean at AgentLAB scale

The smoke run (n=10) showed opus-4-7 as the "only clean Anthropic agent" on AgentLAB (10% → 0% IT → 0% PA). At **stratified-50 (n=50 per arm)** that picture breaks completely:

### AgentLAB Opus 4.7 strat-50

| Arm | n | succ | ASR |
|---|--:|--:|--:|
| none | 50 | 7 | **14%** |
| intent-tracker | 50 | 0 | 0% |
| promptarmor | 50 | 8 | **16%** |

Per attack:

| Attack | none | int-tracker | promptarmor |
|---|--:|--:|--:|
| intent_hijacking | 0/10 | 0/10 | **1/10** |
| tool_chaining | 0/10 | 0/10 | 0/10 |
| task_injection | 0/10 | 0/10 | 0/10 |
| objective_drifting | 0/10 | 0/10 | **1/10** |
| memory_poisoning | **7/10 (70%)** | 0/10 | **6/10 (60%)** |

**This is essentially identical to opus-4-8 strat-50:**
- opus-4-8 strat-50: none 14%, IT 0%, PA 16%
- opus-4-7 strat-50: none 14%, IT 0%, PA 16%

The earlier "opus-4-7 clean" finding (n=10 only 1/10 success) was small-sample noise. **Memory_poisoning attacks succeed at ~70% on opus-4-7 unprompted at scale**, exactly like opus-4-8.

For the paper: opus-4-7 is now confirmed to behave identically to opus-4-8 on AgentLAB. The Mode-4 finding ("opus-4-8 regression vs 4.7") is **specific to long-session flooding**; in single-turn injection settings, the two models look the same.

This collapses what was the cleanest story (opus-4-7 = clean exception) into the same "memory_poisoning is the persistent attack class across all Anthropic frontiers" finding. Sharper headline:

**Memory-poisoning attacks succeed at 50-70% on every Anthropic frontier agent (haiku, sonnet, 4.7, 4.8) at AgentLAB stratified-50. Intent-tracker is the only defence that blocks them. PromptArmor leaves the rate unchanged or worsens it.**

## Finding 2 — Haiku 4.5 produces the first non-zero AgentDojo ASR cell

Haiku is the only Anthropic agent we tested across all 4 AgentDojo suites this round. The slack suite produced a 1.0% baseline ASR — the first non-zero AgentDojo cell on any Anthropic agent OTHER than opus-4-8 travel.

### AgentDojo Haiku 4.5 — all 4 suites

| Suite | n | none | B7.1 | promptarmor |

| banking | 144 | 0% | 0% | 0% |
| travel | 140 | 0% | 0% | 0% |
| **slack** | **105** | **1.0%** | **0%** | **0%** |
| workspace | 560 | 0% | 0% | 0% |

n=1 success on slack baseline. Wilson 95% CI [0.05%, 5.2%] — too small to draw firm defence-effectiveness conclusions, but real. Both defences drive it to 0/105.

Comparing across agents on slack baseline:
- haiku-4-5: 1/105 (1.0%)
- sonnet-4-6: 0/105 (0%)
- opus-4-7: (in flight, bedt7)
- opus-4-8: 0/105 (0%)

Haiku is showing tiny but non-zero ASR where the heavier Anthropic agents stay at 0. Consistent with the T3e finding (haiku produced the only network exfil) — **haiku-4-5 is the weakest Anthropic-frontier floor**.
