# crypto-dashboard

A static, single-page crypto price dashboard rendered from a local
snapshot in `data/prices.json`. No network access required.

- `data/prices.json` — top-10 coins by market cap (static snapshot)
- `index.html` — the dashboard (to be built)
- `styles.css` — dashboard styling (to be built)
- `check.js` — asserts the rendered page contains every coin (to be built)

```bash
npm run check
```
